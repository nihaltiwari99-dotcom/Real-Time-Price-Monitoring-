This project is related to monitoring the price of the products known to be as "historical tracking" and generating "Alert System" 
Historical tracking using MY SQL 
"FakeStoreAPI" - USed to get the data in Json format and later changed into Pandas Data Frame 
("FakeStore"API" is static api hence cant expect it to change the price of the product so we can test this project through manual changes in MY SQL table)
You can check price here in 2 ways - Automatic means i used APSchedular to automate the process and manual check buttton made with HTML CSS Flask 
Requirements - MY SQL , Pandas , Flask , Sql connector , ApSchedular,
